REV MATCHING AUTO — GITHUB PAGES ONLY

Upload the CONTENTS of this folder to your GitHub repository.

FILES
- index.html
- styles.css
- script.js
- README.txt
- assets/rev-matching-auto-homepage.png

IMPORTANT
- Keep index.html in the ROOT of the GitHub repository.
- Keep the assets folder beside index.html.
- Do NOT upload a ZIP inside GitHub.
- This package contains NO Netlify configuration.

GITHUB PAGES SETUP
1. Create a PUBLIC repository named rev-matching-auto.
2. Upload all files and the assets folder.
3. Go to Settings → Pages.
4. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Save.
6. GitHub will provide a public address like:
   https://YOUR-USERNAME.github.io/rev-matching-auto/

The website is plain HTML/CSS/JavaScript and requires no build process.

The cart, search, category filters and account window are front-end demo features.
For live ecommerce, connect the site to Odoo Website/eCommerce.
